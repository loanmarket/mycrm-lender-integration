# Apollo Accreditation Data Download Instruction

This guide details how to obtain an access token for the download endpoint, which provides the most current broker accreditation data generated by the system. This data encompasses all active Australian loan writing brokers, including their accreditation details, general broker information, and social media presence.

# What You Need

These credentials will be given via 1Password:
- Client ID
- Client Secret

Grant type: `client_credentials`<br>
Scope: `machine.accreditation-data-apollo-download`<br>
Authentication URL: https://auth.mycrm.finance/oauth2/aus410jy6cvXYv8j7357/v1/token

# Authenticate Using Okta Credentials
Sample cURL request:
```
curl --location --request POST 'https://auth.mycrm.finance/oauth2/aus410jy6cvXYv8j7357/v1/token' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'grant_type=client_credentials' \
--data-urlencode 'client_id={replace-me}' \
--data-urlencode 'client_secret={replace-me}' \
--data-urlencode 'scope=machine.accreditation-data-apollo-download'
```

This will return a response like this:
```json
{
    "token_type": "Bearer",
    "expires_in": 3600,
    "access_token": "{access-token-here}",
    "scope": "machine.accreditation-data-apollo-download"
}
```

Once you get the `access_token`, you can use it to authenticate to the download endpoint.

# Accessing the Download Endpoint

Sample cURL request:
```
curl --location --request GET 'https://api.mycrm.finance/accreditation-data/download/apollo' \
--header 'Authorization: Bearer {access-token-here}'
```

This will return a response like this:
